Pluto Launcher privacy policy

Pluto Launcher · Anders (andershfranzen) · Updated 12 October 2026

Your information stays on your device

Pluto has no account, ads, analytics, tracking SDKs or remote crash reporting. The developer does not receive your installed-app list, layout, searches, ROMs, notifications or launch history.

Apps, layout and recent launches

Pluto reads launchable app names, icons and shortcuts to display and search them. Favourites, folders, hidden apps, categories, widget IDs and settings are saved in the app’s private storage. Optional recent launches are stored locally; you can clear them or turn history off in Settings. Search queries are used locally and are not saved as a search history.

ROM folders and artwork

Pluto accesses only folders and images you select with Android’s file picker. It saves file references, game names and artwork locally to build your library. Opening a game gives your chosen emulator access to its selected file. Removing a ROM tab deletes Pluto’s library records, not your game files. Emulators and widget providers handle their own data under their own policies.

Notification dots

Optional Android notification access is used for app/profile identifiers, notification flags and badge eligibility. This metadata is held only in memory, including in the background while access is enabled. Pluto does not read or store notification message text or send notification data off the device. Revoke access in Android Settings to stop the listener.

Double-tap screen locking

The optional Accessibility Service API is used only to perform Android’s lock-screen action after your double tap. It cannot retrieve screen content and does not subscribe to accessibility events. No personal data is collected, stored or shared through this service. Disable “Pluto screen lock” in Android’s Accessibility settings to revoke access.

Updates and external links

The Google Play build has no Internet permission or GitHub updater. Google Play handles its updates under Google’s own privacy policy. The GitHub build contacts GitHub only for update checks you permit and downloads you request. GitHub receives normal connection metadata, such as your IP address and Pluto version; no launcher activity is sent. Update checks are optional and downloads require your approval. External support links open in your browser and are subject to the destination’s privacy policy.

Retention and deletion

Pluto’s saved data remains in its private on-device storage until you remove it, clear the app’s storage or uninstall. Android backup is disabled. Revoking file permissions stops future access. Clearing Pluto’s storage does not delete the ROM files or artwork you selected. Pluto has no server account or server-held user records to delete.

Contact

For privacy questions, email anders@afive.dev. You can also report issues through the Pluto Launcher GitHub issue tracker. Avoid including private information in a public issue.
