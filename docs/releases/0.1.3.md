# Pluto 0.1.3 — ROM tabs and cohesive glass

Download `app-release.apk` from this release, open it on Android 11 or newer, and choose
**Update**. Your browser may need permission to install unknown apps.

## Changed

**Your ROMs in console mode**
- Create custom tabs such as **PlayStation 1** from **Settings → Apps → ROM tabs**.
  Choose a ROM folder, a default emulator and a tab name. Games use the same Coverflow
  carousel as apps, with box art and reflections.
- The emulator chooser suggests installed emulators, supports search and lets you choose
  any installed app, including apps hidden from Pluto's drawer. **Ask each time** is
  available too. Open emulator setup and return without losing your tab draft.
- Folder selection supplies an editable tab name. Create and Save stay visible while
  scrolling; advanced launch options stay out of the way. Unsaved changes require an
  explicit discard, and scan errors explain how to recover.
- Games stay in your chosen folder. Subfolders are included, CUE tracks and M3U discs
  are grouped under their playable entry, and common filename tags are removed from
  display names while disc numbers and editions are preserved.
- Collections refresh when you return to Pluto, with a 30-second per-tab throttle.
  **Refresh games** checks immediately. A matching adjacent PNG, JPG or WebP supplies
  box art; online artwork lookup is not implemented.
- DuckStation direct launch works automatically when it is the selected default.
  Other emulators receive Android Open file requests or use the system app chooser;
  compatibility depends on the emulator's launch interface and supported formats.

**Glass, layout and startup**
- Folders, Edit Home, pickers, app actions, settings and nested dialogs now share
  frosted surfaces and neutral translucent controls. Covered pages blur beneath dialogs.
- Landscape panels and folders reserve balanced space around camera cutouts. Compact
  name dialogs fit above the keyboard, and keyboard **Done** saves the name.
- Pluto's startup screen centers the planet on black. A small progress cue appears
  only when loading takes longer than 700 ms, with no tagline or artificial delay.
- Drag apps out of folders onto Home, the dock or another folder.
- Console mode's **Always (launcher stays in landscape)** option holds Pluto in
  landscape. Switching back to Automatic restores the selected rotation behavior.
- First-run setup, settings wording and drawer action surfaces received further polish.

## Verification and limits

- 247 JVM tests passed. Focused Android checks covered database migration, read-only
  ROM URI grants, carousel focus, landscape keyboard entry, emulator selection, draft
  discard and Always → Automatic rotation restoration. The final focused run passed
  all 9 tests.
- The R8 release was reviewed in portrait and landscape. A PlayStation 1 tab created
  through Android's folder picker displayed the cleaned Spyro title and local box art,
  and launched the maintainer's disc dump in DuckStation using their BIOS dump.
- ROMs, BIOS files, emulators and cover art are not included in the APK. Configure
  required BIOS files and emulator settings in your chosen emulator.
- Real-controller behavior, drag haptics and the OnePlus still need hardware verification.

## Updating safely

Android package: `dev.pluto.launcher`; version code: **4**; version name: **0.1.3**.
The APK uses the same Android development signing key as **0.1.2** (certificate SHA-256
`55:65:39:7D:43:DC:5E:5B:CA:F8:81:02:FD:3F:D3:C4:75:2D:6D:00:D1:33:29:75:93:BC:F5:79:0E:77:8B:13`).
Updating from 0.1.2 preserves your layout and preferences; the database migration keeps
your existing launcher data.

The 0.1.1 release used a different signing key. If Android reports a signature conflict,
do **not** uninstall a daily-use build merely to bypass it: uninstalling deletes Pluto's
local organisation and preferences.
