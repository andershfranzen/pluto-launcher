# Pluto 0.1.1 — interface polish

Download `app-release.apk` from this release, open it on Android 11 or newer, and choose
**Update**. Your browser may need permission to install unknown apps.

## Changed

- Translucent drawer with wallpaper-visible background and alpha-masked scroll edges.
- Permanent search field and stable header/category context while typing.
- State-based text editing fixes duplicated or dropped characters during rapid native
  keyboard input. Delayed query echoes cannot rewind input or undo Clear.
- Pinned Appearance, Layout, Apps and General settings navigation with grouped cards,
  stable choice-chip widths and better-spaced steppers.
- Fixed interrupted drawer entrances, overshooting flings, stale controller-focus IDs
  and predictive Back/reduced-motion handling.

## Verification and limits

- 220 JVM tests and 40 Android emulator tests passed for the interface changes.
- Optimised R8 release build; baseline profiles are included.
- Native fast typing was also checked in the optimised release on the emulator.
- Phone visual/frame-time and controller validation remains outstanding. Landscape
  drawer reflow was checked; landscape keyboard smoke automation encountered an emulator
  renderer stall and still needs phone confirmation.

## Updating safely

Android package: `dev.pluto.launcher`; version code: **2**; version name: **0.1.1**.
The APK uses the existing local Android development signing key, not a production/store
key. Android can update an existing Pluto installation only if its signing key matches.
If Android reports a signature conflict, do **not** uninstall a daily-use build merely
to bypass it: uninstalling deletes Pluto's local organisation and preferences.
