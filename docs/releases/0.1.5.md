# Pluto 0.1.5

Update through **Settings → General → Updates**, or download `app-release.apk` and
open it on Android 11 or newer. Updating preserves your layout and preferences.

## Changed

- The alphabetical drawer uses softer glass styling and fades in from 108% size.
- Console mode has calmer coverflow cards, clearer shelf context, smoother shelf
  transitions, and an app/ROM overview grid that returns to the selected carousel card.
- Search finds apps, cached ROMs and app shortcuts, with category-aware results and
  immediate query updates. Shortcut access requires Pluto to be the default Home app.
- Optional iPhone-inspired notification dots cover Home, dock, folders, drawer, search
  and Console. Enable them in **Settings → Apps → Notification dots** and grant Android
  notification-listener access. No notification contents or history are retained.
- Search indexes and wave samples are reused. Console composition and artwork decoding
  are bounded; unchanged ROM shelves retain their objects and unchanged scans avoid
  database writes. Icon warming follows the active viewport. Memory pressure trims
  caches without recycling displayed images, and abandoned shared loads are cancelled.
- Refreshed startup and interaction profiles cover populated Home, richer search,
  decoded ROM covers, Console overview and gamepad shelf switching. Profiling fixtures
  are excluded from the release APK.

## Verification and limits

- All 290 JVM tests and 23 focused Android regressions passed with their prerequisites
  satisfied. Strict journey smoke, both profile-generation tests, full release lint
  and optimized release assembly passed.
- Profiles converged across repeated emulator runs. Ten cold-start samples per
  compilation mode showed effectively unchanged startup (896 ms uncompiled versus
  888 ms with the required profile); this noisy emulator comparison establishes no
  reliable phone speedup. Hardware controller timing and frame-rate gains are unmeasured.
- See [the performance review](../PERFORMANCE_REVIEW.md) for scope, raw measurements
  and validation details.

## Updating safely

Android package: `dev.pluto.launcher`; version code: **6**; version name: **0.1.5**.
The APK uses the same signing key as 0.1.2–0.1.4 (certificate SHA-256
`55:65:39:7D:43:DC:5E:5B:CA:F8:81:02:FD:3F:D3:C4:75:2D:6D:00:D1:33:29:75:93:BC:F5:79:0E:77:8B:13`).

Version 0.1.1 used a different key. If Android reports a signature conflict, avoid
uninstalling a daily-use build merely to bypass it: uninstalling deletes local data.
