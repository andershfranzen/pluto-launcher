Pluto Launcher accessibility review

Version 0.1.7 (8) · dev.pluto.launcher · Android 11 or newer

The optional Accessibility Service API performs Android’s lock-screen action when the user double-taps empty space on Home. Pluto cannot retrieve window content and subscribes to no accessibility events. It collects, stores and shares no personal data through this service.

Open or download the MP4. This is an actual emulator recording from 12 October 2026. Idle time is trimmed and captions are outside the full device frame. The final black display is the recorded screen-lock action; Android reported mWakefulness=Asleep and mLastSleepReason=accessibility.

  1. Start Pluto and open the Home menu → Launcher settings → Layout.
  2. Choose Double-tap to lock and read the separate disclosure. Cancel leaves the feature off.
  3. Retry, choose Agree and continue, and enable Pluto screen lock in Android Accessibility settings.
  4. Accept Android’s permission dialog, return to Home, and double-tap empty space to lock the screen.

The feature is optional. Disable Pluto screen lock in Android Accessibility settings to revoke access. No login, controller or ROM files are needed to review it. Sideloaded builds may require Android’s Allow restricted settings option; that extra step does not apply to installs through Google Play.
