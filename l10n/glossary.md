# Translation glossary

The words Pluto already uses for its own concepts, per language. Keep new and changed strings
consistent with them; if a term should change, change it in every string of that language and
here in the same edit. Terms marked *in sentences* appear inside longer strings (case and
number endings vary); the rest are standalone labels, shown exactly as shipped.

Never translated: Pluto, Android, Google Play, GitHub, Ko-fi, emulator and console names
(DuckStation, RetroArch, PlayStation…), XMB, ROM, file and folder names, and controller
button names printed on hardware (A, B, X, Y, L1, R1, Start, Select).
